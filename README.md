# بيتك عندنا 🏠

موقع عربي (RTL) لعرض منشورات الشقق، مع نظام إدارة مخفي محمي، يتيح:

- للزائر تصفّح منشورات الشقق (صور/فيديو/نص فقط) وعرض تفاصيلها.
- التواصل مع الإدارة بالهاتف أو واتساب على رقم واحد: **01552099055**.
- إرسال طلب «اطلب شقة» بالمواصفات المطلوبة دون تسجيل حساب.
- للإدارة (بعد دخول مخفي) نشر منشورات الشقق ومراجعة طلبات العملاء وتغيير حالتها.

> ⚠️ **ملاحظة أمان مهمة:** هذه الوثيقة والكود **لا يحتويان كلمة المرور الحقيقية أو بيانات العملاء**. كلمة المرور تُضبط على الخادم نفسه ولا تُرفع مع الكود.

## 1) هيكل المشروع

```
├── server.js               # خادم Node.js + Express (الوظائف والحماية الحقيقية)
├── package.json
├── lib/passwords.js        # تجزئة كلمة المرور (scrypt)
├── scripts/
│   ├── set-password.js     # ضبط كلمة مرور الإدارة
│   └── selftest.sh         # اختبارات وظيفية ذاتية
├── config.example.json     # نموذج إعدادات بلا أسرار
├── public/                 # الواجهة (HTML/CSS/JS)
│   ├── index.html          # الشاشة الترحيبية
│   ├── listings.html       # منشورات الشقق
│   ├── detail.html         # تفاصيل الشقة
│   ├── request.html        # نموذج «اطلب شقة»
│   ├── admin.html          # الإدارة المخفية (غير مربوطة لأي زائر)
│   ├── assets/brand.jpg    # ← ضع الشعار الأصلي هنا
│   ├── css/global.css
│   └── js/  (common, listings, detail, request, admin)
├── data/                   # بيانات JSON (خارج public) — منشورة وطلبات منفصلة
│   ├── posts.json
│   └── requests.json
└── uploads/                # الوسائط المرفوعة (تخزين دائم)
```

## 2) التشغيل محليًا

يتطلب **Node.js 20.9 أو أحدث**.

```bash
npm install
npm start          # أو: node server.js
```

يفتح الموقع على: `http://localhost:3000` (يستمع على `0.0.0.0` حتى تعمل المعاينة والاستضافة).

عند أول تشغيل وقاعدة المنشورات فارغة، يزرع الخادم تلقائيًا منشورات شقق حقيقية مع صور من `public/listings-media/` حتى لا يظهر الموقع فارغًا. الزراعة لا تستبدل بيانات موجودة.

### النشر على Vercel

الملف `vercel.json` يوجّه كل الطلبات إلى خادم Express حتى تعمل `/api/posts` والطلبات والإدارة على الرابط العام (مثل `https://prrjffh.vercel.app`). بعد دفع الفرع إلى `main` يعيد Vercel النشر تلقائيًا.

يمكن ضبط كلمة الإدارة على Vercel بمتغير البيئة `ADMIN_PASSWORD` (الافتراضي: `زياد زياد`).

### ضبط كلمة المرور الإدارية (إلزامي قبل النشر)

كلمة المرور تُخزَّن **كتجزئة scrypt** داخل `config.json` (وهو **مستثنى من git** فلا يُرفع أبدًا).

```bash
# كتابةً مباشرة
node scripts/set-password.js "كلمة المرور الجديدة"

# أو بإدخال مخفي أثناء التنفيذ
node scripts/set-password.js
```

> إن لم تُضبط كلمة مرور، يولّد الخادم عند أول تشغيل كلمة عشوائية ويطبعها مرة واحدة في السجل، ثم عليك تغييرها.

## 3) الدخول إلى الإدارة (مخفي عمدًا)

لا يوجد رابط إدارة ظاهر لأي زائر. **اضغط مطوّلًا (ثانيتين)** على زر/رقم التواصل العائم «📞 01552099055» فتظهر شاشة كلمة المرور. الضغط القصير يفتح نافذة التواصل (هاتف/واتساب) دون بدء مكالمة تلقائية.

- الضغط المطوّل يعمل باللمس على الموبايل وبالضغط المستمر بالماوس على الكمبيوتر.
- رفع الإصبع/زر الماوس بعد الضغط المطوّل **لا** يفتح نافذة التواصل.
- التحريك للتمرير يُلغي الضغط المطوّل.
- فتح `admin.html` مباشرة لا يتجاوز الحماية: يُطلب تسجيل الدخول عند غياب جلسة صحيحة.
- إدخال `admin.html` في الروابط عند إغلاق الجلسة يعيد طلب كلمة المرور.

## 4) الحماية المطبّقة (على الخادم)

- كلمة المرور تُجزَّأ بـ scrypt ولا تُخزَّن/تُرسَل كنص ظاهر، ولا يُعتمد على localStorage كدليل دخول.
- جلسات إدارية HttpOnly على الخادم + حماية CSRF (رأس مخصص).
- فحص كلمة المرور على الخادم، والوصول للإدارة والطلبات محمي.
- حد محاولات كلمة المرور: **5 محاولات خاطئة ⇒ حظر مؤقت 10 دقائق**.
- حد طلبات الشقق: **5 لكل عنوان خلال 15 دقيقة** + مفتاح إرسال يمنع التكرار من نفس الصفحة.
- تنقية كل إدخالات المستخدم من الوسوم (لا تُنفَّذ HTML/JS في المتصفح — عرض كنص آمن).
- فحص محتوى الوسائط (لا نثق بالامتداد): تُرفض HTML وSVG والملفات التنفيذية وكل ما ليس JPG/PNG/WebP للصور وMP4/WebM للفيديو.
- حدود الأحجام: صورة ≤5MB، فيديو ≤20MB، إجمالي المنشور ≤40MB، حتى 8 صور وفيديو واحد.
- وسائط بأسماء آمنة عشوائية خارج `public`، ومنع الوصول بأسماء غير مطابقة أو تجاوز مسار.
- بيانات بكتابة ذرية متسلسلة (لا تُستبدل بملف فارغ عند خطأ)، وعدم وجود إحصائيات/أرقام وهمية (كل الأرقام من بيانات حقيقية).

## 5) حدود النسخة الحالية (كما في المواصفات)

- المنشور: عنوان 3–90، مكان 2–150، وصف 10–4000 حرفًا.
- الطلب: اسم 2–80، منطقة 2–150، ميزانية 2–100 (نص مرن)، وصف 10–3000، ورقم موبايل مصري 11 رقمًا أو رقم دولي (يدعم الأرقام العربية).
- أقصى طلبات محفوظة: **2000** (قابل للضبط عبر `MAX_REQUESTS`).
- حالات الطلب: جديد / قيد المراجعة / متوفر / غير متوفر. تصفية + صفحات من 20 طلبًا.
- التواصل يتم يدويًا بالهاتف/واتساب؛ تغيير الحالة لا يرسل شيئًا تلقائيًا، وزر واتساب يفتح **مسودة** قابلة للتعديل فقط.

## 6) التشغيل (deployment) والنشر الحقيقي

- تخزين الكود على GitHub **لا** يشغّل Node.js، وGitHub Pages وحده لا يشغّل النشر المحمي أو حفظ الطلبات.
- الاستضافة الدائمة يجب أن **تدعم Node.js وHTTPS** مع قرص دائم (`data/` و`uploads/`) ونسخ احتياطية.
- عند رفع إصدار جديد على خادم يعمل: **لا تستبدل** مجلدات `data/` و`uploads/` حتى لا تُفقد بيانات حقيقية.
- كلمة المرور تُضبط على الخادم (`config.json`) ولا تُرفع مع الكود.

## 7) اختبارات القبول

بعد تشغيل `node server.js` في طرفية، شغّل من أخرى:

```bash
bash scripts/selftest.sh
```

نفّذ الموقع فعليًا وتحقق من: شاشة الترحيب، الحالة الفارغة، التفاصيل، نشر منشور نصي بلا وسائط (بلا معرض فارغ)، خياري الهاتف/واتساب على الرقم الصحيح، الضغط المطوّل دون الضغطة العادية، رفض كلمة خاطئة وقبول الصحيحة، بقاء البيانات بعد إعادة التشغيل، وصول الطلب للإدارة فقط، حفظ الحالة، ارتباط زري الرد برقم العميل، رفض الملفات والمدخلات غير الصالحة، تسجيل الخروج، والتنسيق على مقاسات الموبايل والكمبيوتر.

> حدود الاختبارات: أُجريت الوظائف على الخادم الفعلي (اختبار آلي + يدوي للمسارات). لا يمكن ضمان 100% لكل جهاز/استضافة/خدمة اتصال خارجية، ولا نُدّعي أن رسالة أُرسلت أو مكالمة أُجريت — ما اختُبر هو الرابط والوظيفة فقط.
